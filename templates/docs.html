1. Project Abstract

The AI Coding Tutor for C Programming is an intelligent educational platform tailored specifically for first-year Computer Science and Engineering (CSE) undergraduates. First-year students learning C frequently experience high cognitive friction with manual memory management, pointer dereferencing, buffer overflows, and cryptic compiler diagnostics. Conventional generative AI assistants typically bypass the learning process by immediately providing complete corrected solutions, fostering dependency and preventing students from developing mental models of program state and execution flow.

This platform introduces a hint-first pedagogical paradigm featuring a 3-tier progressive hint disclosure mechanism (Subtle Nudge → Concept & Line Focus → Corrected Solution & Fix). It combines an intelligent static rule-based C analyzer, a GCC compiler interface with isolated temporary directory execution, interactive debugging checklists, 10 common beginner mistakes, and continuous tutor quality feedback logged to SQLite.

2. Problem Statement

Undergraduate C programming pedagogy faces two critical modern challenges:

  • Cryptic Diagnostic Barriers: Standard GCC output (e.g. error: expected ';' before 'printf' or silent Segmentation Faults from wild pointers) fails to explain why the bug occurred in terms accessible to beginners.
  • Premature Answer Revelation: Existing Large Language Models (LLMs) solve programming problems unconditionally, eliminating the "productive struggle" necessary for students to master algorithmic debugging, invariant checks, and pointer mechanics.

9. Security & Sandbox Boundaries

Compiling and running untrusted student code requires strict security boundaries:

  • Ephemeral Temporary Directories: Every compilation executes in a uniquely generated OS temp directory (e.g., tempfile.mkdtemp()) which is guaranteed to be deleted in a finally: block.
  • Process Execution Timeouts: A strict 3.0-second execution timeout is enforced via subprocess.run(timeout=3.0). Runaway infinite loops or blocking inputs are terminated immediately.
  • Output Buffer Capping: Terminal output is capped at 64 KB (65,536 bytes) to prevent memory exhaustion from runaway printf loops.
  • Honest Dependency Transparency: If a native GCC compiler is not detected in the host environment, binary execution is cleanly prevented, and the platform transparently guides the user through installation rather than inventing fake execution outputs.
10. Ethical Use of AI in Education

AI tutoring systems must be designed to augment human learning, not replace critical thinking:

  • Scaffolding over Direct Answers: Defaulting to Level 1 and Level 2 hints ensures students engage their problem-solving faculties.
  • Academic Integrity: The tutor explains the principles of memory management and language syntax rather than encouraging blind copy-pasting.
  • Privacy Preservation: All student code analysis and quiz attempts are stored in a private local SQLite database with zero tracking.
